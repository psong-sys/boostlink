BOOST LINK - FIRST ONLINE TEST (about 15 minutes)
==================================================
Paul = host. Friend = joins. Do the steps in order.

BEFORE (both of you)
--------------------
1. Friend: extract the NEWEST friend-pack.zip into your game folder (say yes to replace).
   Then run exvs-english\exvs-ui.exe and choose install, so your menus match Paul's.
2. Both: be in the same ZeroTier network. Paul, find your ZeroTier IP in the launcher's
   PLAY tab (Host shows it) and send it to your friend.
3. Both: launcher > SETTINGS. Network adapter = your REAL one (Ethernet or Wi-Fi),
   not ZeroTier. Compare machine serials: they must be different.
4. Both: click "Check my PC". Fix anything marked FAIL. If it offers "Fix firewall",
   click it and say Yes to the Windows prompt. (Friend: "Match host" can only pass
   once Paul has started in step 5, so do the check again after that.)

THE TEST
--------
5. Paul: PLAY > Host > Start. Wait for the title screen.
   Open http://localhost:28090/status in a browser and keep it visible.
6. Friend: PLAY > Join > type Paul's ZeroTier IP > "Check my PC" (Match host should
   now be OK) > Start.
7. Both: log in with your card, go to online versus, pick a unit, and start searching
   at the SAME time (count down on Discord).
8. Paul: watch the status page. You should see "2 searching", then a new line under
   "Recent matches", then two lines under "Connection results".

WHAT THE RESULT MEANS
---------------------
* Fight starts / SUCCESS        -> It works! Play 2-3 matches and note how inputs feel
                                   (fine / a bit delayed / laggy). Screenshot the status page.
* FAIL_TIMEOUT or               -> Both click "Fix firewall" in Check my PC, then search again.
  FAIL_TIMEOUT_NO_PACKETS          Still failing? Both set the adapter to ZeroTier in
                                   SETTINGS, restart, and try again.
* FAIL_RTT_OUT_OF_LIMIT         -> Ping over 300 ms. Tell Claude; the host can raise the limit.
* Nobody matched (status page   -> Friend: run Check my PC, look at "Match host" and "VPN".
  never shows 2 searching)
* An error code on screen       -> Take a photo of the screen with the code.

AFTER (send these to Claude, from BOTH PCs)
-------------------------------------------
- A screenshot of Paul's status page.
- exvs-launcher\traffic.log
- the exvs-launcher\logs folder
- exvs-online\check-report.txt
- any error codes / photos
