    Your card

    Everyone in an online match needs different IDs. New card IDs give you a new, empty card. Your old card stays on your card server, and typing the old values back in brings it back.

    Pilot name & customizing

    Your pilot name, favorite suits, stickers, BGM and titles are edited in the card server's own web page.

    Opens the editor in your browser and starts the card server if it isn't running. Play once first so your card exists, then sign in there with the chip ID and access code on the left.

    Network

    The game and the Live Monitor both use this adapter, and it's written to config.ini and lmnfig.ini. Don't pick Radmin or ZeroTier here. Those are only for the host's IP.

    Display

    Live Monitor

    The game needs the Live Monitor running, or it stops at "LIVEMONITOR DISCONNECT". The launcher starts it before the game and closes it after.

    Shortcuts & files

    "Boost Link Play" starts straight into the game with your saved settings. "Boost Link" opens this window.

    Keyboard key names like Z, UpArr, 1 (NumPad). Separate several keys with commas.

    Controller controller button numbers. DeviceId 16 means every connected controller.
